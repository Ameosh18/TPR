# World Physiotherapy Day Poster Prompt

**Concept:** The Movement Thread
**Target tool:** ChatGPT (DALL-E image generation)
**Output:** Instagram story, 9:16, 1080 x 1920
**Angle:** Awareness and education, with quiet clinic branding
**Occasion:** World Physiotherapy Day, 8 September

## Note on the annual theme

World Physiotherapy publishes a themed campaign each year. The theme for this
year has not been confirmed in this document, so the prompt below is written to
work independently of it. If you have the official theme, add it as a line under
"Concept" in the prompt and adjust the headline in the text layer section.

## Why the image carries no text

DALL-E renders long words unreliably and misspells clinical vocabulary often.
Generate the artwork clean, then set the headline, the Marathi line and the
footer in Canva over the empty zones the prompt reserves. This also keeps the
type in Lora and Inter, matching the site.

## The prompt

Paste this into ChatGPT as a single message.

```
Create a vertical 9:16 poster image, 1080 x 1920 pixels, for a physiotherapy
clinic's Instagram story.

Concept: a single continuous unbroken line drawn in sage green travels the full
height of the frame from bottom to top. Near the bottom the line is coiled and
compressed, knotted and tight. As it rises it loosens and opens out, and along
the way it traces the shapes of human movement: the curve of a spine, the bend
of a knee, the arc of a walking stride. At the top it resolves into a simple
minimal outline of a person walking upright and free, drawn in that same single
stroke. The line never breaks from the bottom of the frame to the top.

Style: minimalist editorial line art. Single consistent stroke weight, generous
negative space, calm and clinical but warm. Flat vector illustration. No 3D, no
shading, no texture, no gradient mesh, no photographic elements. The reference
point is a modern healthcare brand's campaign poster, not a hospital pamphlet.

Colour: the background is a soft off white with the faintest warm green tint,
hex #F2F7EA. The continuous line starts sage green, hex #A8CC78, at the bottom
and deepens gradually to deep forest green, hex #2C5016, as it rises. Use no
other colours.

Composition: leave the top 250 pixels and the bottom 600 pixels as almost empty
background, with only the beginning and the end of the line entering those
zones, so that text can be placed there afterwards. The line work lives in the
middle band of the frame. The whole composition must read clearly at thumbnail
size on a phone.

Text: do not render any text, letters, numbers or words anywhere in the image.

Avoid: photographs, realistic humans, faces, hands, anatomical or medical
diagrams, skeletons, muscle charts, stethoscopes, red crosses, clipart icons,
drop shadows, lens flare, watermarks, borders and frames.
```

## Refinement follow-ups

Send these one at a time if the first result misses.

- "The line is breaking in places. Redraw it as one truly unbroken continuous
  stroke from the bottom edge to the top edge."
- "Too busy. Reduce the number of movement shapes to three and increase the
  empty space around them."
- "The bottom 600 pixels are not clear enough. Empty that zone completely apart
  from the single line entering it."
- "Make the walking figure at the top simpler, closer to a two or three stroke
  pictogram."

## Dark variant

For a second story frame in the same set, swap the colour paragraph for:

```
Colour: the background is deep forest green, hex #1C2E10. The continuous line is
sage green, hex #A8CC78, brightening to a pale green, hex #C4DE9A, as it rises.
Use no other colours.
```
